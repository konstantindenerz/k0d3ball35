# Use the spare controller pins (encoder, display) in a later PCB revision

## Context

D1, D2, D3 and D9 (right half) are broken out as jumper and test pads. A later revision could add footprints for an encoder or a small display without changing the matrix.

## Acceptance criteria

- [ ] Decision which feature is worth the height and the battery cost
- [ ] Footprints added in the generator behind an option, DRC clean
