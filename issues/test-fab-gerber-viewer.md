# Check the gerber zip in a gerber viewer before ordering

## Context

The fabrication files are generated by `scripts/export.sh` and only verified by KiCad's own DRC. A second pair of eyes in an independent viewer (JLCPCB upload preview, gerbv, tracespace) catches wrong layer assignment, missing drill files or an open outline.

## Acceptance criteria

- [ ] Upload `hardware/main-pcb/k0d3ball36-gerbers.zip` to the JLCPCB preview: 2 layers detected, dimensions about 120 x 94 mm, outline closed, 30 mm cutout present
- [ ] PTH and NPTH drill files both detected; counts per tool match docs/06-fabrication.md
- [ ] Silkscreen readable, RIGHT text on top, LEFT text on the bottom layer, no text over pads
- [ ] Same check for `hardware/sensor-pcb/fab/*.zip`
