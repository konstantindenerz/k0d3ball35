# 34 mm cradle variant as fallback

## Context

If 25 mm balls are hard to source or the tracking feel is not convincing, the same main PCB should
accept a 34 mm cradle. The cutout and hole circle of the main PCB must leave room for it.

## Acceptance criteria

- [ ] 34 mm STL exported from the parametric cradle
- [ ] Clearance check against the surrounding keycaps on the layout (may require the ball zone to move slightly outboard)
- [ ] Noted as an option in the build guide
