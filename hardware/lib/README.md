# Project libraries

Symbols (`k0d3ball35.kicad_sym`) and footprints (`k0d3ball35.pretty/`) shared by every KiCad project in
this repository. Both project folders reference them through their local `sym-lib-table` and
`fp-lib-table` with `${KIPRJMOD}/../lib/...`, so the repository is self-contained and needs no
global library configuration.

| Item | Origin | Notes |
|------|--------|-------|
| `PMW3610DM-SUDU` (symbol + footprint) | this project | footprint origin is the optical centre; includes the 16.96 x 8.60 mm body cutout on Edge.Cuts; generated by `hardware/sensor-pcb/generate.py fp` |
| `XC6206P182MR`, `FPC_6P`, `C`, `R`, `TestPoint`, `MountingHole`, power symbols | this project | drawn for this repository, generated by `hardware/sensor-pcb/generate.py sym` |
| `FPC_0.5mm_6P_FH12-6S` | KiCad official library `Connector_FFC-FPC:Hirose_FH12-6S-0.5SH_1x06-1MP_P0.50mm_Horizontal` | renamed copy |
| `SOT-23`, `C_0603`, `R_0603`, `TestPoint_D1.0mm` | KiCad official footprint libraries | renamed copies |
| `MountingHole_M2` | this project | 2.2 mm plain hole, 2.0 mm courtyard radius |
